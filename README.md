# UNLOAD / DOWNLOAD

겉은 중세 판타지, 속은 SF인 스토리 RPG.
웹(UNLOAD)에서 엔딩까지 무료로 즐기고, 엔딩에서 게임을 '다운로드'하는 행위 자체가 이야기의 클라이맥스가 된다.

> 스토리 스포일러를 포함하므로 이 리포는 **private**로 유지한다.

## 지금 할 수 있는 것

- 타이틀: 게임 이름 없이, 실제 날짜·시각·계절과 진행 상황에 따라 매번 다르게 그려지는 마을
- 프롤로그(수확제 전날 → 수확제 → 다음 날)와 1~3장을 탑다운 필드에서 플레이. 게임 시계가 돌고 사람들이 하루 일과를 산다
- 선택창 없음. 떨어진 빵을 주워주고, 노래를 끝까지 듣고, 곁에 가만히 서 있는 행동이 갈림길
- **CONTINUE(되돌리기)를 네다섯 번 누를 때마다 가장 마음을 준 사람이 지워진다.** 아무도 그걸 알아채지 못한다. RESET & START로도 돌아오지 않는다
- 말 걸기: 사람마다 장면별 대화가 있다. 흰 대화창에 한 글자씩, 사람마다 다른 '도도도' 목소리, 중요한 말은 노란 형광펜. 미아는 일러스트(표정 차분)가 선다
- 마을 밖: 전체 지도(지상·지하·숨은 은하), 길 맵, 들를 수 있는 마을(서리 마을·항구·드워프 마을·빈 마을·엘프 마을·옆 마을), 분수 광장의 교역 도시 로웬, 깊은 숲의 마법 도시 아스테라
- 사람이 산다: 우리 마을에 가족 단위로 서른일곱 명(각자 집과 하루 일과), 도시마다 열 명 남짓, 항구·서리 마을·드워프 마을·옆 마을·길 위의 마을들도 가족과 이웃이 산다(배경 주민 서른다섯 명 추가, 모두 아흔 명 남짓)
- 싸움: **탑뷰 실시간 액션**(세피리아·하데스 계열). 싸움터는 그 땅의 바닥과 나무로 그려지고, 타격 불꽃·연타·쓰러질 때 조각이 튄다. 무리가 여럿 몰려오고, 바닥의 붉은 예고를 읽고 피하고 벤다. 동료 없이 혼자 싸운다. 땅마다 다른 적(스물다섯 가지 남짓, 무리는 8~14마리), 보스(토르크·레온·길 잃은 기사·정리자의 그림자)
- 생활과 몸: 먹고 일하고 쉬는 만큼 체중·근육·마음가짐이 바뀌고 도트와 전투 수치에 보인다. 행동 파밍(벌목·채광)과 히든 스킬, 가방과 선물, 마을 습격, 퀘스트·단서 수첩
- 가게와 동전: 마을·도시마다 가게(잡화점·과일 좌판·상인 조합·대장간·생선 가게·여관·물약 가게). 주인에게 말을 걸면 사고판다. 싸워서 동전을 벌고, 산 먹을 것은 건네거나 직접 먹는다
- 아이템·장비 등급 색(일반·고급·희귀·영웅·전설). 장비가 액션 전투의 스킬을 바꾸고, 갑옷은 주인공 도트의 옷 색을 바꾼다

## 실행

필요: Node.js 20+

```bash
npm install
npm run dev       # http://localhost:5173
```

조작

| 어디서 | 키 |
| --- | --- |
| 필드 | `WASD`/방향키 이동(같은 방향 두 번 → 달리기), `E`/`Space` 말 걸기·살펴보기·대화 넘기기, `C` 스테이터스, `I` 가방(U 먹기), `J` 수첩, `M` 전체 지도, `+`/`−` 작은 지도 확대 · 소리는 오른쪽 위 단추나 `Esc` 옵션 |
| 싸움 | 방향키 이동, 마우스 조준·클릭 공격, `Q` `W` `E` `R` 스킬(찌르기·휘두르기·막기·돌진), `1`~`8` 아이템, 지면 `R` 되돌리기 · `Esc` 물러나기 |
| 휴대폰 | 왼쪽 아래 조이스틱, 오른쪽 아래 버튼 (PC에서 보려면 주소 뒤에 `?touch=1`) |

EXE 빌드(Windows)는 [Rust](https://rustup.rs)와 Microsoft C++ Build Tools가 추가로 필요하다: `npm run tauri build`

## 테스트

```bash
npm run check      # 콘텐츠 검증 + 단위 테스트 + 빌드 (커밋 전에)
npm run test:e2e   # 실제 게임을 헤드리스 브라우저로 완주 (처음 한 번: npx playwright install chromium)
```

플레이테스트: 주소에 `?playtest`를 붙여 열면 그 브라우저에 플레이 기록이 남는다(ESC → 플레이 기록 저장). `node tools/playlog-report.mjs 파일.json`으로 읽는다. 자세한 건 [docs/플레이테스트.md](docs/플레이테스트.md).

GitHub에 푸시하면 같은 검사가 자동으로 돈다(Actions 탭). 자세한 건 [docs/구현.md](docs/구현.md#테스트).
