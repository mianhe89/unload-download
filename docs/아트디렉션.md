# 아트 디렉션

이 게임의 그림은 세 겹으로 나뉜다. 겹마다 쓰는 자리와 그림체가 다르다.

| 겹 | 어디에 쓰나 | 그림체 레퍼런스 | 지금 상태 |
| --- | --- | --- | --- |
| 1. 필드 픽셀 | 탑다운 필드, 타이틀 일러스트, 소품 | 코어키퍼 계열 16px 치비 | 코드로 생성 중 (`content/art/`) |
| 2. 일러스트 | 이벤트 CG, 전투 스킬 컷인, 대화 중요 장면 | 에픽세븐 계열 서브컬처 일러스트 | 미착수 (커미션 예정) |
| 3. SD 이모트 | 삐짐·당황·졸림 같은 귀여운 순간 | 말랑한 블롭 몸통 SD (도로롱 계열) | 미착수 |

> 레퍼런스는 **분위기와 비율의 참고**로만 쓴다. 다른 게임의 캐릭터를 그대로 따라 그리지 않고, 모든 캐릭터와 SD는 이 게임의 오리지널 디자인이다. 레퍼런스 이미지 파일은 리포에 넣지 않는다.

## 1. 필드 픽셀 (코어키퍼 계열)

- **16×16 치비**: 머리가 몸의 절반 이상. 눈은 점 두 개.
- **외곽선**은 보라빛 검정 `#2a1f2e` 하나로 통일. 순수 검정은 쓰지 않는다.
- **실루엣 원칙**: 멀리서 색을 빼고 봐도 누군지 알아봐야 한다. 캐릭터마다 실루엣 키가 하나씩 있다(아래 표).
- 모든 캐릭터는 같은 몸 템플릿(`content/art/body.js`)에 머리·소품 레이어(`content/art/layers.js`)를 얹는다.
- 방향 3개(아래/위/옆) × 걷기 3프레임. 왼쪽은 오른쪽을 뒤집어 쓴다.
- 타일과 소품도 16px. 2칸 이상 큰 것(모닥불)은 랜드마크로 따로 그린다.

## 2. 일러스트 (에픽세븐 계열)

평소의 '예쁜 그림'은 이쪽이다.

- 셀 채색 + 부드러운 그라데이션, 깨끗하고 얇은 선
- 전투 궁극기 컷인은 화면을 가로지르는 구도, 강한 빛 이펙트
- 히로인 스탠딩은 대화창 위에 크게 띄우지 않는다(미연시처럼 보이지 않게). **중요한 순간에만 CG로** 쓴다.
- 색은 필드 픽셀 팔레트와 같은 계열로 맞춰, 픽셀 → 일러스트 전환이 튀지 않게 한다.

## 3. SD 이모트 (말랑 블롭 계열)

가끔 나오는 귀여운 순간용. 무거운 이야기 사이의 숨구멍이다.

- **몸통은 둥근 떡 모양**, 짧은 다리 넷 또는 팔 둘. 머리카락과 장식으로 누군지 알아본다.
- **얼굴은 최소한**: `:3`, `-_-`, `>_<` 정도. 눈은 크게 혹은 반쯤 감긴 선.
- 쓰는 순간: 삐짐, 졸림, 당황, 배고픔, 칭찬받음. 필드 말풍선 옆이나 대화창 구석에 작게 뜬다.
- **지워짐과 대비**: 지워진 사람의 SD는 다시 나오지 않는다. 귀여웠던 만큼 빈자리가 커지게.

## UI

- 글꼴: Galmuri11 (SIL OFL 1.1, 픽셀 한글). 오프라인으로 번들된다.
- 대화창: 화면 아래, 초상화 없이 이름표 + 문장. RPG의 대화창이지 미연시 화면이 아니다.
- 말풍선: 인물 머리 위, 크림색 바탕.
- 타이틀: 게임 이름을 쓰지 않는다. 메뉴는 오른쪽 아래 영어로 작게 (`CONTINUE`, `RESET & START`).

## 타이틀 일러스트

언덕에서 마을을 내려다보는 뒷모습. 매번 코드로 새로 그린다.

| 바뀌는 것 | 근거 |
| --- | --- |
| 하늘색, 별, 해/달 | 플레이어의 실제 시각 (새벽/낮/노을/밤) |
| 달의 모양 | 실제 날짜의 달 위상 |
| 땅 색, 눈 | 실제 계절 |
| 날씨, 구름·새 배치 | 날짜로 정해지는 시드 (하루 동안 같고, 매일 다르다) |
| 미아가 곁에 있는가 | 이야기 진행 (1장부터 혼자) |
| 굴뚝 연기, 초소 등불, 꽃밭, 벤치의 사람 | 호르트·톰·리네·페르가 지워졌는가 |
| 세상의 색 | 지워진 사람 수만큼 바랜다 |
| 하늘의 금 | 누적 로드 횟수 |
| 종탑 위의 그림자 | 프롤로그를 끝냈는가 |
