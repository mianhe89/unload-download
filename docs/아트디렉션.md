# 아트 디렉션

이 게임의 그림은 세 겹으로 나뉜다. 겹마다 쓰는 자리와 그림체가 다르다.

| 겹 | 어디에 쓰나 | 그림체 레퍼런스 | 지금 상태 |
| --- | --- | --- | --- |
| 1. 필드 픽셀 | 탑다운 필드, 캐릭터, 건물·나무·소품, 파티클 | Ninja Adventure 팩(CC0) 기반 16px, 재채색·덧그리기로 변형 | 적용됨 (`assets-src/`, `npm run assets`) |
| 2. 일러스트 | 대화 중 인물, 이벤트 CG, 전투 스킬 컷인 | 에픽세븐 계열 서브컬처 일러스트 | 미아 3장(기본·웃음·수줍음), 임시 배경 CG 5장. 나머지 인물은 그림이 오는 대로 (Firefly 프롬프트: [일러스트_프롬프트.md](일러스트_프롬프트.md)) |
| 3. SD 이모트 | 삐짐·당황·졸림 같은 귀여운 순간 | 말랑한 블롭 몸통 SD (도로롱 계열) | 미착수 |

> 레퍼런스는 **분위기와 비율의 참고**로만 쓴다. 다른 게임의 캐릭터를 그대로 따라 그리지 않고, 모든 캐릭터와 SD는 이 게임의 오리지널 디자인이다. 레퍼런스 이미지 파일은 리포에 넣지 않는다.

## 1. 필드 픽셀 (CC0 팩 기반)

바탕은 **Ninja Adventure Asset Pack (pixel-boy, CC0)**. 상업 이용·수정·재배포가 자유롭고 출처 표기 의무도 없다(크레딧엔 감사의 뜻으로 적는다). 원본과 라이선스 기록: `assets-src/ninja-adventure/LICENSE.md`.

- **해상도는 16px로 통일**한다. 팩이 16px이고, 고급스러움은 픽셀 수가 아니라 음영·외곽선·조명에서 나온다. 32px 캐릭터를 섞으면 배경과 어긋난다.
- **원본은 손대지 않는다.** `assets-src/`에 원본을 두고, `npm run assets`(= `tools/build-assets.mjs`)가 변형본을 `public/assets/gen/`에 만든다.
- **캐릭터 변형**: 인물마다 팩의 바탕 캐릭터 하나를 고르고(`content/characters/<이름>.js`의 `sprite`), 팔레트를 바꾸고(recolor), 필요하면 픽셀을 덧그린다(edits: 리네의 화관, 페르의 깃털). 두 인물이 같은 바탕을 쓰지 않는다(테스트로 강제).
- **건물·소품 변형**: 종탑은 팩에 없어 팩의 색·외곽선으로 찍었다(48×112): 돌 기단과 아치 문, 벽돌 탑신, 아치 종루의 금빛 종, 뾰족한 주황 지붕. 침대도 같은 식으로 찍었다.
- **줄등**: 축제 날 광장 깃대 사이에 처진 등불 줄(`field/systems/Garlands.js`), 밤엔 불빛.
- **맵**: 흙길은 8×8 사분면 자동 타일로 이어 그리고(`src/field/autotile.js`), 풀포기·들꽃을 흩뿌린다. 건물·나무는 아래쪽 끝 기준으로 앞뒤가 정해져 **나무 뒤로 걸어가면 가려진다.** 나무는 줄기만 막는다.
- **조명**: 밤에는 어둠을 칠하고 불빛 자리를 오려낸 뒤(실제로 밝아짐) 따뜻한 빛을 더한다. 플레이어 주변엔 작은 랜턴 빛.
- **공기**: 모닥불 불꽃·불티·연기, 밤의 반딧불, 낮의 떨어지는 잎. 모닥불은 이야기를 따라 타오름 → 사그라듦 → 꺼짐.
- 대본용 작은 소품(빵, 화관, 반지 등)은 아직 코드로 그리되, 팩과 어울리게 같은 외곽선(`#141b1b`)을 두른다.

## 2. 일러스트 (에픽세븐 계열)

평소의 '예쁜 그림'은 이쪽이다.

- 셀 채색 + 부드러운 그라데이션, 깨끗하고 얇은 선
- 전투 궁극기 컷인은 화면을 가로지르는 구도, 강한 빛 이펙트
- **진짜 일러스트가 있는 인물은 대화창으로 말할 때 대화창 오른쪽 뒤에 상반신이 선다.** 주인공·내레이션 차례에는 어둡게 남는다. 대화창은 중요한 장면에만 쓰므로, 평소 걷는 대사(말풍선)에는 일러스트가 뜨지 않는다.
- 그림이 없는 인물은 대화창 안의 작은 도트 얼굴(팩 Faceset)로 대신한다. **코드로 그린 임시 일러스트는 쓰지 않는다**(조잡해 보인다).
- 표정 차분(웃음·수줍음 등)을 둘 수 있다. 대사에 `{ face: '표정' }`.
- 아주 중요한 순간에는 배경 CG 위에 인물을 세운 **인물 CG**로 쓴다(`content/cg.js`의 `bg` + `figure`).
- 색은 필드 픽셀 팔레트와 같은 계열로 맞춰, 픽셀 → 일러스트 전환이 튀지 않게 한다.

### 여성 캐릭터 체형 비율

여성 캐릭터를 새로 넣을 때 아래 비율(12명 중)로 섞는다. 골반은 대체로 넓고 섹시한 실루엣으로 그린다.

| 체형 | 비율 | 그리는 법 |
| --- | --- | --- |
| 글래머 · 노출 있음 | 6 | 굴곡이 드러나는 몸에 노출 있는 의상 |
| 글래머 · 노출 없음 | 2 | 몸에 붙는 옷이라 굴곡이 티 나는 차림 |
| 평범 | 3 | |
| 빈약 | 1 | |

- **모든 캐릭터는 성인이다.** 빈약 체형이나 동안 캐릭터도 얼굴, 비율, 설정 나이로 성인임이 분명하게 보여야 한다.
- 노출은 의상 디자인의 범위로 다루고 성적인 장면은 넣지 않는다(기획서 리스크 표의 '연령 등급·심사'). 노출 수위는 웹 공개와 플랫폼 심사 등급에 직접 걸리므로, 출시 플랫폼을 정할 때 다시 확인한다.

## 3. SD 이모트 (말랑 블롭 계열)

가끔 나오는 귀여운 순간용. 무거운 이야기 사이의 숨구멍이다.

- **몸통은 둥근 떡 모양**, 짧은 다리 넷 또는 팔 둘. 머리카락과 장식으로 누군지 알아본다.
- **얼굴은 최소한**: `:3`, `-_-`, `>_<` 정도. 눈은 크게 혹은 반쯤 감긴 선.
- 쓰는 순간: 삐짐, 졸림, 당황, 배고픔, 칭찬받음. 필드 말풍선 옆이나 대화창 구석에 작게 뜬다.
- **지워짐과 대비**: 지워진 사람의 SD는 다시 나오지 않는다. 귀여웠던 만큼 빈자리가 커지게.

## UI

- 글꼴: Galmuri (SIL OFL 1.1, 픽셀 한글). 대화 본문은 Galmuri14, 나머지는 Galmuri11(굵게는 Galmuri11 Bold). 오프라인으로 번들된다.
- 아이템 등급 색: 일반 회색 · 고급 초록 · 희귀 파랑 · 영웅 보라 · 전설 주황 (`content/items/items.js`). 히든 스킬 N/R/SR/SSR도 같은 색.
- 대화창: 중요한 장면과 말 걸기 대화. 화면 아래, **흰 종이 바탕**에 금 테두리와 모서리 장식(`src/ui/DialogBox.js`, 금색은 `src/ui/kit.js`). 이름표는 인물 색을 진하게 한 둥근 명패. 글자는 한 글자씩 인물별 '도도도' 소리와 함께 찍히고, 중요한 말은 노란 형광펜으로 강조한다. 다른 창(수첩·가방·HUD)은 그대로 밤색+금. 일러스트가 있는 인물은 대화창 뒤에 서고, 없으면 작은 도트 얼굴(팩 Faceset).
- 말풍선: 평소 대사. 인물 머리 위, 흰 둥근 풍선 + 꼬리 + 인물 색 띠. 톡 튀어나오고 글자가 찍힌다. 멀어서 안 들리는 말은 `…`로 흐리게.
- 내레이션(걸으며): 주인공 위 허공에 그림자 진 글이 떠오르며 흐려진다.
- 지워진 이름: 마을 사람 대사 속에서 `▒■░▓` 글자로 깨진다.
- 타이틀: 게임 이름을 쓰지 않는다. 메뉴는 오른쪽 아래 영어로 작게 (`CONTINUE`, `RESET & START`).

## 타이틀

그림이 아니라 **지금 이 순간의 마을**을 그대로 보여준다(필드와 같은 맵·그림). 게임 이름은 없다.

| 바뀌는 것 | 근거 |
| --- | --- |
| 빛 (새벽/낮/노을/밤) | 플레이어의 실제 시각 |
| 떨어지는 것 (벚꽃잎·낙엽·눈) | 실제 계절 |
| 날씨(비·눈), 카메라가 머무는 곳 | 날짜 시드 (하루 동안 같고 매일 다르다) |
| 광장에 서 있는 사람 | 지워진 사람은 없고 흔적(빈 좌판·통 등)만 |
| 모닥불 | 시작 전·축제 중엔 타오르고, 그 뒤로 꺼짐 |
| 미아가 곁에 있는가 / 종탑 앞 정리자 | 1장부터 혼자, 정리자가 서 있다 |
| 화면이 이따금 튐 | 누적 로드 횟수 (상한 있음) |

설정은 `src/scenes/title/titleSetup.js`(순수 함수, 테스트됨).
