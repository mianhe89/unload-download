# 플레이테스트

이 게임이 재미있는지는 두 가지로 가른다.

1. **첫 30분이 그 자체로 즐거운가.** 반전을 모르는 사람이 프롤로그부터 1장 들개 싸움까지 지루해하지 않는가.
2. **첫 지워짐에서 소름이 돋는가.** 에다가 없어진 아침, 그리고 네 번째 로드에 아끼던 사람이 없어졌을 때, 플레이어가 원인을 스스로 이어 붙이는가.

머리로는 판단할 수 없으니 남이 하는 걸 보고 기록으로 확인한다.

## 진행

- 테스터 3~5명. 게임에 대해 아무 설명도 하지 않는다(장르, 반전, '로드' 이야기 전부).
- 주소에 `?playtest`를 붙여 한 번 열어 준다(예: `http://localhost:5173/?playtest`). 그 브라우저에는 기록이 켜진 채 기억되니 다음 날은 주소 없이 열어도 된다. 끄려면 `?playtest=0`.
- **나흘 이상, 하루 10~20분씩** 하게 한다. 타이틀의 CONTINUE가 로드라서, 네 번째 날쯤 첫 로드 지워짐을 겪는다. 한자리에서 한 시간을 하면 이걸 못 본다.
- 첫날은 뒤에서 조용히 지켜본다. 화면을 녹화하면 좋다. 도와주지 않는다.
- 끝나면 ESC → **플레이 기록 저장**으로 파일(`playlog-날짜.json`)을 받는다.

### 끝나고 묻는 것 (이 세 가지만)

1. 가장 기억에 남는 사람이 누구야?
2. 누가 없어졌어?
3. 왜 없어졌다고 생각해?

3번에 '내가 다시 켜서(로드해서)'에 가까운 답이 나오면 훅이 닿은 것이다. 2번에 이름을 못 대면 정이 덜 붙은 것이다.

## 기록 읽기

```bash
node tools/playlog-report.mjs playlog-*.json
```

| 항목 | 보는 것 |
| --- | --- |
| 세션 | 언제 켜서 몇 분 했고, 몇 번 로드했고, 누가 지워졌고, 어디서 껐나. 같은 데서 자꾸 끄면 거기가 문제다 |
| 페이즈별 머문 시간 | 아래 '프롤로그 측정'의 예상과 비교한다 |
| 반응 없는 구간 | 60초 넘게 대사·말 걸기·살펴보기·줍기·싸움이 없었던 곳. 길을 헤맸거나 할 일을 몰랐던 자리 |
| 멈춰 서 있던 곳 | 30초 넘게 안 걸은 곳. 길을 잃었거나, 일부러 가만히 서 있어 봤거나(그건 좋은 신호) |
| 말 건 사람 | 누구에게 정이 갔나. 지워진 사람과 겹치면 그 지워짐은 아팠을 것이다 |
| 싸움 | 결과, 걸린 시간, 되돌리기 횟수 |
| 본 장면 | 어떤 이벤트를 봤고 어떤 걸 놓쳤나(숨은 갈래를 찾았나) |

기록은 세이브와 따로 둔다(`ud.playlog`, `src/core/playtest/PlayLog.js`). RESET & START로도 지워지지 않는다. 남기는 것: 페이즈·길 맵 들어섬, 장면 시작·끝, 말 걸기, 살펴보기, 줍기, 생활 행동, 가게, 싸움(시작·결과·되돌리기), 로드와 지워짐, 바깥을 향한 질문의 답, 10초마다 서 있는 칸과 걸은 거리, 창을 닫은 때.

## 프롤로그 측정 (2026-11-06)

대사 길이와 걷는 거리로 잰 예상치다. 실제 테스트 기록과 비교하려고 남긴다. 걷는 속도는 초당 4.5칸, 대화창 대사는 한 글자 0.03초에 읽는 시간(0.08초/자)을 더했다.

| 페이즈 | 예상 | 하는 일 |
| --- | --- | --- |
| 수확제 전날 (prep) | 4~5분 | 여섯 명 중 셋을 도우면 미아가 부른다(아니면 5분 뒤). 대사 약 2분 40초, 걷기 약 30초 |
| 수확제의 밤 (festival) | 3~5분 | 빵 줍기·불씨 밟기·화관 줍기·노래 끝까지 듣기·미아 곁에 가만히. 둘을 하면(아니면 2분 30초 뒤) 에다가 온다 |
| 다음 날 아침 (morning) | 3~4분 | 대장간 → 미아와 전령 → 셀레나 → 루. 한 줄로 이어진다 |
| 그날 밤 (night) | 1분 | 종탑 앞의 정리자 |
| **프롤로그 합계** | **12~15분** | 첫 30분의 나머지는 1장: 견습 첫날, 루의 훈련, 들개 떼(첫 싸움) |

### 걸리는 것

1. **에다를 안 만나고 지나갈 수 있다.** 전날은 여섯 중 아무 셋이면 끝나서, 에다를 건너뛰면 에다를 보는 건 수확제 밤의 28초뿐이다. 그 다음 날 아침 에다가 없다. 정이 붙을 틈이 없어 첫 지워짐이 '설정 소개'가 된다(기획서가 피하자고 한 것). 에다는 꼭 거치게 하는 편이 낫다.
2. **아침부터 밤까지는 거의 보기만 한다.** 대화창 장면이 이어진다(미아·전령 44초, 셀레나 27초, 루 41초, 정리자 54초). 이 사이 플레이어가 하는 일은 걷기뿐이다. 에다가 없어진 걸 손으로 확인할 거리(흔적 소품 셋: 탄 빵 바구니, 주인 없는 화관, 모루의 자국)는 있지만 모두 들러도 되고 안 들러도 되는 곳이다.
3. **정리자가 너무 많이 말한다.** "제일 무거운 것부터 치워야 해", "이름을 아는 건 너뿐" — 새 뼈대(사라짐은 뒤에, 짧은 의문 한 줄)와 달리 프롤로그 끝에서 규칙을 거의 설명한다. 플레이어가 스스로 이어 붙일 몫이 줄어든다.
4. **첫 싸움이 20분쯤 뒤다.** 프롤로그엔 싸움이 없다. 'RPG'라는 걸 전하는 첫 손맛이 1장 들개 떼까지 미뤄진다.
5. **첫 반응까지는 빠르다.** 시작 장면(약 20초) 뒤 가장 가까운 페르까지 2.4초, 다른 사람도 3~7초. 전날과 축제는 반응 사이가 짧아 괜찮아 보인다. 실제 기록의 '반응 없는 구간'으로 확인한다.

### 로드 지워짐

- 첫 로드 지워짐은 4번째 로드다(`ERASE_GAPS = [4, 5]`). 프롤로그를 끝내고 CONTINUE를 누를 때가 첫 로드다.
- 로드 1~3번째에 남는 어긋남: 종이 하나씩 더 울림(`{bells}`), 톰의 "이 얘기 아까도 하지 않았나?", 페르의 뒷소절, 엿듣는 대화의 한 줄. 테스터가 이걸 알아챘는지 3번 질문으로 확인한다.
