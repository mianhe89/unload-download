# 구현 정리

기획은 [기획서.md](기획서.md), 그림 규칙은 [아트디렉션.md](아트디렉션.md)에 있다. 이 문서는 **코드가 어떻게 짜여 있고, 무엇을 어디에 추가하는가**를 다룬다.

## 한눈에

```
화면 흐름   Boot ──► Title ──► Field ⇄ UI(겹침)
                      ▲          │
                      └──────────┘  챕터 끝 / 타이틀로
                     (예정) Field ──► Battle(사이드뷰) ──► Field
```

- **Field**: 탑다운으로 걸어 다니는 곳. 한 번에 한 페이즈(어디서·누가·무슨 일이)를 돌린다.
- **UI**: Field 위에 겹쳐 도는 씬. 대화창·말풍선·HUD. 카메라 배율과 무관하게 글자가 선명하다.
- **Battle**: 필드에서 조우하면 넘어가는 사이드뷰 전투(포켓몬 구조 + 라테일·에픽세븐 연출). 아직 없다.

## 핵심 규칙: 지워짐 (`src/core/world/WorldMemory.js`)

- **CONTINUE = 로드**. 누적 로드 +1, 그리고 마을 사람 한 명이 지워진다.
- 누가 지워지나: 지워질 수 있는 사람(`erasable: true`) 중 **호감도가 가장 높은 사람**. 동점이면 `ERASE_ORDER` 순서.
- **RESET & START**는 진행(run)만 처음으로 돌린다. 세계(world)의 지워짐과 로드 횟수는 남는다.
- 지워진 사람은 필드에 배치되지 않고, 그 자리에 `remnant`(흔적 소품)가 남는다. 대본은 `unlessErased` / `ifErased` 조건으로 갈린다.

## 페이즈와 이벤트 (`content/chapters/*/phases.js`)

선택창은 없다. 갈림길은 플레이어의 행동이 만든다.

```js
{ id: 'hort.spill', when: { unlessErased: 'hort' }, trigger: { near: 'hort', r: 4 }, run: 'festival.hort_spill' }
```

| trigger | 뜻 |
| --- | --- |
| `{ near, r }` | 인물/장소 근처에 가면 (r: 타일) |
| `{ zone }` | 구역에 들어서면 (`maps/village.js`의 zones) |
| `{ timer }` | 페이즈 시작 후 n초 |
| `{ afterFlag, delay }` | 플래그가 켜지고 n초 뒤 |
| `{ dwell, r, seconds, ticks }` | 그 곁에 누적 n초 머물면. ticks로 도중 말풍선 |
| `{ idle, near, r, minTime }` | 그 곁에서 가만히 n초 |
| `{ pickedAll, near?, r? }` | 흩어진 물건을 다 주웠으면 (+그 사람에게 가면) |
| `{ count: [플래그…], n }` | 플래그 n개 이상 |

- 이벤트는 한 번만 실행되고 `done.<id>` 플래그로 기억된다(이어하기 후에도 반복되지 않음).
- `when`은 대본 조건과 같은 문법이다(아래).
- 인물 배치에도 `when`을 달 수 있다(예: 셀레나와 이야기한 뒤에만 루가 있음).
- E 키로 말을 걸면 `talk.<페이즈>.<인물>` 컷신이 있으면 처음 한 번 실행, 이후엔 그 인물의 혼잣말.

## 컷신 대본 (`content/chapters/*/script.js`)

```js
'festival.hort_thanks': [
  T('hort', '오, 다 주워왔냐!'),
  T('tom', '어라. 이 얘기 아까도 하지 않았나?', { minLoads: 1 }),
  { aff: { hort: 2 }, flag: 'ev.hort' },
],
```

| 노드 | 뜻 |
| --- | --- |
| `N(문장)` / `T(인물, 문장)` | 내레이션 / 대사 |
| `B(인물, 문장)` | 말풍선 (대화창 없이) |
| `{ fx }` | `shake` `bell` `flash` `fade` `glitch` |
| `{ aff: { 인물: n } }` | 호감도 |
| `{ flag }` | 플래그 켜기 (aff와 한 노드에 같이 써도 된다) |
| `{ act: 'spawnPickups', group, prop, items, expire? }` | 물건 흩뿌리기 |
| `{ act: 'spawnNpc', id, at \| near:'player', offset }` | 인물 등장 |
| `{ act: 'walkAway', id, to }` / `{ act: 'despawn', id }` | 퇴장 |
| `{ phase }` | 같은 장의 다음 페이즈로 |
| `{ end: 'title', next: { chapter, phase } }` | 타이틀로, 다음 이어하기 지점 지정 |

조건(모든 노드): `ifErased` `unlessErased` `ifErasedAny` `minLoads` `maxLoads` `ifFlag` `unlessFlag`
문장 안 치환: `{bells}`(13 + 로드 횟수), `{loads}`

## 에셋 파이프라인

```
assets-src/ (CC0 원본)  ──npm run assets──►  public/assets/gen/  ──Boot──►  Phaser 텍스처
                         재채색·덧그리기            manifest.json            물체 프레임·애니메이션 등록
```

- `npm run dev`, `npm run build` 전에 자동으로 돈다(predev / prebuild). 결과물은 git에 올리지 않는다.
- **캐릭터 추가**: 팩에서 바탕 캐릭터를 `assets-src/.../Actor/Characters/<이름>/`에 복사 → `content/characters/<id>.js`에 `sprite: { base, recolor, edits }`. 바꾸려는 색이 원본에 없으면 테스트가 실패한다(오타 방지).
- **물체 추가**: 팩 시트에서 사각형을 찾아 `content/art/pack.js`의 `OBJECTS`에 `rect`(그림)와 `foot`(충돌) 등록 → 맵에 `O('이름', x, y)`.
- **맵 수정 후**: `npm run validate`가 막힌 칸, **걸어서 닿을 수 없는 인물·물건·구역**까지 잡는다.

## 저장과 확장성 (DB 대비)

```
게임 로직 ──► WorldMemory ──► SaveRepository ──► StorageAdapter
                                 (메모리 캐시)      ├─ LocalStorageAdapter (지금, 웹)
                                                   ├─ MemoryAdapter (테스트)
                                                   ├─ TauriFileAdapter (예정, 데스크톱: 게임 폴더에 세이브)
                                                   └─ RemoteAdapter (예정, 서버 DB)
```

- **어댑터 계약**은 비동기 `read / write / remove` 셋뿐이다(`core/storage/StorageAdapter.js`). 원격 DB로 바꿀 때 어댑터 하나만 새로 쓰고 `core/storage/index.js`에서 고른다.
- **Repository**는 시작할 때 한 번 읽어 메모리에 올리고, 이후 쓰기는 비동기로 흘려보낸다. 게임 루프가 네트워크를 기다리지 않는다.
- **세이브 스키마**는 버전이 있다(`core/save/SaveSchema.js`). 필드를 바꾸면 `VERSION`을 올리고 `MIGRATIONS`에 변환을 추가한다. 이 구조가 그대로 DB 테이블/문서의 기준이 된다.
  - `world`: 지워짐, 로드 횟수 — 세계의 기억
  - `run`: 장, 페이즈, 플래그, 호감도 — 현재 진행
  - `meta`: 생성·수정 시각, `playerId`(계정 연동 자리)
- **공유 데이터**(서버 공통 붕괴, 정신체 도움, 도달률)는 `core/world/GlobalWorld.js` 한 곳으로만 나간다. 지금은 꺼져 있다.
- 조작 정책: 개인 데이터는 막지 않는다. 공유 데이터만 서버에서 상한 검증.

## 새 콘텐츠 추가하기

**인물**: `content/characters/<id>.js` 작성 → `index.js`에 등록. 새 머리·소품이 필요하면 `content/art/layers.js`에 레이어 추가. 미리보기로 확인.

**장**: `content/chapters/<장>/phases.js`, `script.js` 작성 → `chapters/index.js`에 등록. 이전 장 마지막 컷신의 `end.next`로 이어 준다.

**이벤트**: 해당 페이즈의 `events`에 한 줄 + `script.js`에 컷신 하나.

**맵**: `content/maps/village.js`의 `build()`에 사각형 배치. 장소(`spots`)와 구역(`zones`)에 이름을 붙이면 대본에서 이름으로 부른다.

추가한 뒤엔 항상 `npm run check` (검증 + 단위 테스트 + 빌드).

## 테스트

원칙: **"망가졌나?"는 기계가, "재밌나?"는 사람이** 확인한다. 기능을 넣을 때 테스트를 같이 넣는다.

| 층 | 무엇을 | 어디 | 명령 | 시간 |
| --- | --- | --- | --- | --- |
| 콘텐츠 검증 | 라벨 오타, 막힌 칸의 인물·물건, 지워진 사람이 말하는 대사, 켜지지 않는 플래그, 소프트락 | `tools/lib/validateContent.mjs` | `npm run validate` | 1초 |
| 단위 | 지워짐 규칙, 세이브 이관·저장 실패, 대본 조건, 이벤트 계기, 날짜 유틸, 에셋 빌드·재채색·종탑 변형, 물체 사각형, 맵 충돌, 자동 타일, 타이틀 일러스트 | `tests/unit/` | `npm test` | 3초 |
| 논리 플레이스루 | **모든 지워짐 조합(16가지)**으로 봇이 프롤로그를 끝까지 플레이 | `tests/unit/content.test.js` | `npm test` | 포함 |
| E2E | 빌드한 실제 게임을 헤드리스 Chromium으로 완주 → CONTINUE → 가장 아낀 사람이 지워졌는지, RESET 후에도 안 돌아오는지 | `tests/e2e/` | `npm run test:e2e` | 2~3분 |

- **CI**: GitHub에 푸시하면 `.github/workflows/ci.yml`이 위 네 층을 자동으로 돌린다. 실패하면 리포 Actions 탭에서 원인과 스크린샷을 본다.
- E2E는 처음 한 번 `npx playwright install chromium`이 필요하다.
- E2E는 게임이 여는 `window.__game`, `window.__ud`로 상태를 읽고 플레이어를 순간이동시킨다(`tests/e2e/game.js`).
- 버그를 고치면 **그 버그를 재현하는 테스트를 먼저** 넣는다(예: `script-runner.test.js`의 aff+flag 회귀 테스트).
- 새 이벤트 계기(trigger)를 만들면 `event-director.test.js`에, 새 장을 만들면 `content.test.js`의 플레이스루에 추가한다.

## 개발 명령

```bash
npm run dev                              # 웹 개발 서버
npm run build                            # 웹 빌드 → dist/
npm run tauri dev                        # 데스크톱 창으로 실행 (Rust 필요)
npm run tauri build                      # EXE
npm run check                            # 검증 + 단위 테스트 + 빌드 (커밋 전에)
npm run validate                         # 콘텐츠 검증
npm test                                 # 단위 테스트 (npm run test:watch: 저장할 때마다)
npm run test:e2e                         # 실제 게임 자동 플레이
npm run assets                           # 에셋 빌드 (dev/build 전에 자동)
npm run preview:title                    # 타이틀 일러스트 미리보기 → title-preview.png
```

브라우저 콘솔: `await __ud.wipeAll()` 후 새로고침하면 세계까지 완전 초기화. `__game`은 Phaser 게임 객체.
